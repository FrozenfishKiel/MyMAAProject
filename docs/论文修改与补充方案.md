## 二、 第三章撰写方案 (自动化部署系统核心架构设计)

本章为核心内容，需重点体现混合视觉感知与强化学习状态建模的工程落地能力。

### 3.1 系统总体架构设计
针对塔防类手游《明日方舟》动态多变的战场环境，传统依赖固定坐标或单一图像模板的流水线脚本往往难以胜任。为此，本文设计了一套基于“感知-决策-控制”闭环运作的智能体控制系统。其核心运作流程如下：首先，通过 ADB 协议以设定帧率从安卓模拟器底层获取原始游戏画面；随后，利用混合视觉感知模块（YOLOv8 与 MOG2 等算法）从复杂的高频特效中提炼出干员与敌人的关键动态特征；接着，将提取的高维信息重构为三通道状态张量，并输入以 PPO 为核心的强化学习决策大脑中，由神经网络评估战场局势并输出最优的部署动作；最后，动作控制模块将离散动作解析为物理滑动坐标，通过 ADB 指令注入游戏，完成一个完整的马尔可夫决策周期。

### 3.2 混合视觉感知模块设计
本系统的视觉感知模块摒弃了不稳定的全屏幕模板匹配方案，转而采用以深度学习结合传统计算机视觉的混合架构，确保了特征提取的鲁棒性。

*   **基于 YOLO 的干员状态实时检测**：在干员部署落地阶段，游戏画面的动态转场极易导致传统模板匹配漏检。通过引入轻量级 YOLO 模型，系统能够实时捕捉干员模型上方的血条中心点坐标。结合工程上设计的三次心跳检测机制，即使在极端特效干扰下，也能稳定判定干员是否成功部署及当前生存状态。
*   **基于 MOG2 的动态敌人雷达构建**：游戏背景的复杂性与干员技能特效构成了显著的视觉噪声。为精准定位敌方单位，系统利用 `cv2.createBackgroundSubtractorMOG2` 提取画面前景。进一步地，通过施加形态学滤波（开闭运算）消除离散噪点与特效干扰，系统能够精准提取移动敌人的连通域质心，从而构建出极具信息密度的“敌人动态雷达”。
*   **基于模板匹配的 UI 状态机导航兜底**：在关卡自动重启、异常界面跳转等非战斗场景下，系统调用 OpenCV 的归一化相关系数（`TM_CCOEFF_NORMED`）算法实现状态机的兜底导航，确保智能体能够在长期无人值守的状况下稳定运行。

### 3.3 强化学习马尔可夫决策过程 (MDP) 建模
马尔可夫决策过程的构建是连接感知信息与行动策略的桥梁。为了提升训练效率，本文对状态空间与动作空间进行了降维重构。

*   **状态空间 (State Space) 降维重塑**：系统未直接将 RGB 原彩图像输入神经网络，而是人工合成了尺寸为 $C=4, H=72, W=128$ 的四通道特征张量。具体而言：通道一为游戏原始画面的灰度图保留全局语境；通道二为融合高低台与禁署区域的地形先验掩膜；通道三承载基于 MOG2 提取的动态敌人雷达掩膜；通道四则为手牌区职业特征映射图。在通道四的构建中，系统首先通过亮度阈值判定剔除处于冷却状态或费用不足的卡牌，随后通过模板匹配识别干员职业，并赋予特定的灰度值以示区分，从而实现手牌状态的语义化编码。
*   **动作空间 (Action Space) 离散化定义**：智能体的动作空间被定义为 `MultiDiscrete` 结构。该空间解耦为 12 维度的选卡策略（精准对应干员槽位，移除了无意义的闲置动作）、10×5 的网格化坐标部署选择，以及 4 个方向的朝向参数，实现了将复杂战术意图向底层控制指令的降维。
*   **基于空间几何的奖励函数重塑 (Reward Shaping)**：针对塔防游戏中奖励反馈极其滞后（往往在关卡结束时才结算）的信用分配难题，本文创新性地设计了基于空间几何的密集型即时奖励机制。为防止反向传播中的梯度爆炸，整体奖励幅度被精细缩放至 +1.0 到 -0.05 区间。基础兜底机制通过 Action Masking 对违规操作（如部署在非法地形、费用不足或网格被占用）施加 -0.05 的惩罚；一次合规的部署动作可获得 +1.0 的基础奖励。更为关键的是，系统实时计算部署位置与雷达侦测到的敌人质心之间的欧氏距离，距离越近则追加奖励（至多 +0.5），过远则予以衰减惩罚（-0.2）。此外，系统利用反正切函数 (`math.atan2`) 计算干员朝向与敌人的相对角度，对“面向敌人迎击”的策略给予 +0.3 的奖励，背对则微弱惩罚（-0.1）。此机制极大地加速了智能体掌握“将卡牌丢到敌人脸上并正对敌人”的高阶战术动作。

## 三、 第四章撰写方案 (强化学习环境建模与实验分析)

本章旨在通过详实的数据与曲线论证第三章所述架构的有效性及模型的收敛能力。

### 4.1 实验环境与超参数配置
实验基于 Python 3 平台进行，核心算法依托 PyTorch 框架及 Stable-Baselines3 强化学习库实现。在 PPO 算法超参数配置上，学习率被设定以确保稳定收敛，经验回放的 `n_steps` 参数设为 128，批大小 `batch_size` 设为 64，折扣因子 $\gamma$ 取 0.99 以兼顾短期与长期收益。基准测试环节则通过融合开源项目 MAA 辅助完成。

### 4.2 训练过程与收敛性分析
*(注：撰写论文正文时请在此处插入 Tensorboard 输出的回合平均奖励曲线图与价值损失曲线图)*
从训练过程记录的 Tensorboard 曲线可以清晰观察到智能体策略的演进态势。在回合平均奖励（ep_rew_mean）曲线上，训练初期呈现显著的震荡特征，这是由于智能体处于随机探索阶段，频繁触发违规操作（如部署于不可通行网格）而遭遇系统拦截并扣分。随着训练步数的增加，曲线逐渐呈现出稳步上升并最终趋于平缓的态势。这表明智能体已成功解析了基于空间几何的 Reward Shaping 信号，掌握了“靠近敌人并保持正面迎击”的战术规律。同步观察价值损失（value_loss）曲线，其呈现出平滑下降的趋势，印证了 Critic 网络对当前状态张量价值评估的精准度正在不断提升。

### 4.3 模型评估与实际战例分析
在关闭探索率（设定 `deterministic=True`）的评估模式下，系统在典型关卡（如 1-7）中进行了实战测试。定性观察表明，AI 能够敏锐地捕捉由 MOG2 雷达锁定的红点（移动敌人）信息，极其精准地将手中干员部署于敌人行进路线的周围，并无一例外地做出了迎击朝向选择。这一表现充分证明了本文设计的三通道状态合成技术与距离/角度奖励重塑机制在复杂动态场景下的成功应用。

### 4.4 系统的局限性分析
尽管本研究搭建的“视觉-控制-训练”闭环框架被证实具有高度的可行性，但在工程实践中仍存在一定的局限性。主要挑战源于执行器噪声（Actuator Noise）对马尔可夫决策过程的破坏。由于安卓模拟器底层触控响应存在物理波动，相同的 ADB 拖拽指令有极小概率被游戏客户端拒收（即表现为“手滑”操作未生效）。这种底层的不稳定性为环境引入了极度的非平稳随机性。当智能体在探索过程中遭遇大量由于执行器噪声导致的虚假负反馈时，往往会陷入探索与利用的困境（Exploration-Exploitation Dilemma），在评估模式下偶发短期的局部最优死锁。受限于算力资源与训练周期的限制，模型尚未达到理论上的完美收敛状态。然而，本文提出的技术路线已为后续基于更稳定的 API 接口或通过延长强化学习周期以克服环境随机性提供了坚实的工程基础和理论参考。

## 四、 第五章补充方案 (总结与展望)
在总结全文研究成果的基础上，需要结合实际情况展望未来的改进方向。其中重点提及：
虽然基于 YOLO 的血条检测和 MOG2 敌人雷达有效解决了位置感知的问题，但目前系统尚未整合精细的“干员职业与技能语义识别”模块。由于缺乏对干员职业类型（如重装、狙击、医疗）特性的深入理解，智能体有时会做出不符合职业特性的微观策略。未来工作将探索引入视觉-语言多模态大模型（VLM）或基于对比学习的细粒度图像分类器，使得智能体能够理解“什么卡能在什么地形发挥最大作用”，从而在更加宏观和复杂的战场中展现出接近人类甚至超越人类的统帅指挥能力。
