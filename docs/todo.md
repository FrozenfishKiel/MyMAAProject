# 明日方舟 RL 自动化端到端训练项目进度报告

## 📝 当前进度与已完成工作 (截至 2026-03-30)
我们已经成功跑通了整个 PPO 强化学习的端到端自动化训练循环！环境能够在战斗结束后自动识别 UI 并重新进入关卡，且实现了模型的定期自动保存。

**具体完成的技术点：**
1. **逆向优先级状态机 (Reverse Priority State Machine)**：重写了 `_auto_restart_battle` 的 UI 导航逻辑，倒序检查状态（战斗中 -> 编队界面 -> 关卡详情 -> 地图选关），彻底解决了 AI 在编队界面反复识别 "1-7" 导致死循环的问题。
2. **多尺度金字塔模板匹配 (Multi-Scale Pyramid Matching)**：升级了 `TemplateMatcher` 的算法，支持 0.8x 到 1.25x 的动态缩放匹配，完美解决了模拟器分辨率缩放和 UI 拉伸导致的识别失败问题。
3. **动态 ROI (感兴趣区域) 限制**：在 `game_env.py` 中为不同的 UI 元素精准划分了识别区域，大幅降低了误触率，并允许我们在局部区域使用更低的匹配阈值。
4. **ROI 框选辅助工具**：编写了 `roi_selector.py` 脚本，支持通过鼠标拖拽交互式获取精准的 ROI 坐标。
5. **无干预状态检测**：给齿轮识别添加了 `check_only=True` 参数，只检测是否进入战斗而不触发点击，避免了误暂停。
6. **自动存档机制**：在 `train.py` 的回调函数中加入了每隔 100 步自动保存模型 (`policy_latest.zip`) 的功能，防止训练崩溃导致白跑。
