# 明日方舟 RL 自动化端到端训练项目进度报告

## 📝 当前进度与已完成工作 (截至 2026-03-30)
我们已经成功跑通了整个 PPO 强化学习的端到端自动化训练循环！环境能够在战斗结束后自动识别 UI 并重新进入关卡，且实现了模型的定期自动保存。

**具体完成的技术点：**
1. **逆向优先级状态机 (Reverse Priority State Machine)**：重写了 `_auto_restart_battle` 的 UI 导航逻辑，倒序检查状态（战斗中 -> 编队界面 -> 关卡详情 -> 地图选关），彻底解决了 AI 在编队界面反复识别 "1-7" 导致死循环的问题。
2. **多尺度金字塔模板匹配 (Multi-Scale Pyramid Matching)**：升级了 `TemplateMatcher` 的算法，支持 0.8x 到 1.25x 的动态缩放匹配，完美解决了模拟器分辨率缩放和 UI 拉伸导致的识别失败问题。
3. **动态 ROI (感兴趣区域) 限制**：在 `game_env.py` 中为不同的 UI 元素精准划分了识别区域，大幅降低了误触率，并允许我们在局部区域使用更低的匹配阈值。
4. **ROI 框选辅助工具**：编写了 `roi_selector.py` 脚本，支持通过鼠标拖拽交互式获取精准的 ROI 坐标。
5. **无干预状态检测**：给齿轮识别添加了 `check_only=True` 参数，只检测是否进入战斗而不触发点击，避免了误暂停。
6. **自动存档机制**：在 `train.py` 的回调函数中加入了每隔 100 步自动保存模型 (`policy_latest.zip`) 的功能，防止训练崩溃导致白跑。

## 🎯 远期核心规划：敌人动态捕捉与智能部署引导 (The "Radar" Approach)

**核心需求：**
目前 RL Agent 已经学会了在绿色的可部署格子上下干员，但它的部署行为是“盲目”的。它不知道敌人在哪里，也不知道该朝哪个方向部署才能阻挡敌人。我们需要一种**算力消耗极小、且能有效过滤技能特效**的方法，把动态的敌人从 2D 游戏画面中提取出来，并引导 AI 朝着敌人的方向进行部署。

**技术难点：**
1. **YOLO 成本过高**：训练全类别敌人的 YOLO 模型工作量极大，且推断速度较慢，不适合高频的 RL 试错。
2. **特效干扰**：单纯的帧间差分法（Frame Differencing）会将所有技能特效（火球、爆炸）都识别为移动物体。
3. **静止目标剔除**：需要区分地图背景、已部署的静止干员，以及正在移动的敌人。

**设计方案与技术路径：背景建模 (MOG2) + 图像分层输入 + 空间奖励引导**

### 第一阶段：视觉输入改造 (AI 的“雷达透视图”)
不使用沉重的目标检测模型，纯靠 OpenCV 传统算法提取运动实体。

1. **背景建模提取前景 (Background Subtraction - MOG2)**：
   - 使用 `cv2.createBackgroundSubtractorMOG2()`。
   - 算法会逐渐学习静止的地图和干员（标记为黑色背景）。
   - 正在移动的敌人会被标记为白色的前景区块（Foreground Mask）。
2. **形态学滤波除噪 (Morphological Opening)**：
   - 对前景 Mask 进行**开运算**（先腐蚀后膨胀），像“橡皮擦”一样擦除细碎、闪烁、短暂的技能特效噪点。
   - 结合面积阈值（过滤过大或过小的白块），留下结实、稳定移动的敌人躯干轮廓。
3. **多通道状态输入 (Multi-Channel State Observation)**：
   - 将原始 RGB 游戏画面转换为灰度图（1通道）。
   - 叠加一层**敌人雷达图**（MOG2 处理后的二值化黑白图，仅敌方位置为白，1通道）。
   - 叠加一层**可部署区域图**（提取画面中绿格子的二值化黑白图，1通道）。
   - 最终组合成一个 3 通道的张量（Tensor），喂给 PPO 的 **NatureCNN (三层卷积+全连接)** 提取特征。这样 AI 就能同时“看”到环境、敌人位置和可下兵的位置。

### 第二阶段：动作空间设计
规范 AI 的输出，使其能精确控制部署坐标和朝向。
- 动作空间需要包含：`[X坐标, Y坐标, 部署方向(0上, 1下, 2左, 3右)]`。

### 第三阶段：奖励函数 (Reward Function) 的智能引导
通过计算干员落子点与敌人白块的几何关系，给予 AI 针对性的奖惩，迫使其学会“迎击”。

在 `game_env.py` 的 `step()` 函数中新增以下奖励结算逻辑：
1. **距离奖励 (Distance Reward)**：
   - 提取“敌人白块”的中心坐标。
   - 计算 AI 部署干员坐标 `(X, Y)` 与最近敌人中心点的欧氏距离。
   - **规则**：如果部署点在敌人周边的有效阻挡/攻击半径内（例如 2 个网格内），给予大额正奖励（如 `+5.0`）；如果部署在远离敌人的无效角落，给予负面惩罚（如 `-2.0`）。
2. **朝向奖励 (Facing Reward)**：
   - 计算最近的敌人相对于刚部署干员的相对方位角（上/下/左/右）。
   - **规则**：如果 AI 输出的“部署方向”动作恰好对准了敌人所在的方位，给予极高的正反馈（如 `+10.0`）；如果背对敌人，给予严重惩罚（如 `-5.0`）。
