# AIPVZ: AI决策流程调研报告

## 1. 整体AI架构
`pvz-ai-with-strategy-learning` 项目采用混合架构，将AI逻辑分为两个不同的阶段：
1. **游戏前植物选择**：结合计算机视觉 (CV) 和客户端-服务端API决策模型。
2. **游戏内战术执行**：由自定义的深度强化学习 (Deep Q-Network, DQN) 代理驱动，在模拟的Gym环境中进行交互。

## 2. 游戏内决策逻辑：强化学习 (DQN)
核心的实时游戏玩法由深度Q网络 (`dqn_agent.py`) 处理，该网络通过在自定义环境 (`pvz_env.py`) 中最大化奖励来学习玩《植物大战僵尸》。

### 2.1 状态提取 (观察空间)
AI通过多模态状态字典感知游戏世界 (`PVZEnv`)：
- **`lawn` (草坪)**: 形状为 `[5行, 9列, 通道数]` 的3D张量网格。通道表示5x9网格上不同实体（例如10种植物和2种僵尸）的独热编码 (one-hot encoded) 出现情况。
- **`sun` (阳光)**: 代表当前阳光资源的连续标量值。
- **`plants_remaining` (可用植物)**: 跟踪10种不同植物的冷却时间和可用状态的数组。

### 2.2 神经网络架构
为了处理这些状态，DQN结合了卷积神经网络 (CNN) 和多层感知机 (MLP)：
- **卷积特征提取器**：处理5x9的 `lawn` 网格以理解空间关系。它使用三个 `Conv2d` 层（32 -> 64 -> 64 通道，3x3卷积核，ReLU激活），随后是 `AdaptiveAvgPool2d((1, 1))` 来展平空间特征。
- **特征融合**：从CNN提取的空间特征与 `sun` 和 `plants_remaining` 的数值进行拼接。
- **全连接动作头**：融合后的特征向量通过一个全连接层（512个单元，ReLU激活），输出所有可能动作的预测Q值。

### 2.3 动作选择与空间
AI使用 **epsilon-greedy（ε-贪心）策略** 做出决策：
- **探索 (Exploration)**：以 `epsilon` 的概率（在训练过程中从1.0衰减到0.05）采取随机的有效动作，以探索新的策略。
- **利用 (Exploitation)**：在其他情况下，选择预测Q值最高的动作。
- **动作空间**：被定义为一个映射到单个整数的 `MultiDiscrete` 空间，代表元组 `(行, 列, 植物类型)`。由于是5x9网格和10种植物，最多有450种不同的动作。

### 2.4 奖励设计
环境通过基于规则的奖励来塑造AI的行为：
- **正向奖励**：消灭僵尸会获得分数（例如，豌豆射手击杀+140到+150，寒冰射手击杀+120）。
- **负向奖励 (游戏结束)**：如果僵尸到达屏幕左侧导致游戏结束，将受到高达 `-1000` 的严厉惩罚。
- **无效动作惩罚**：对于无效操作（如阳光不足时尝试放置植物、放置在已被占用的地砖上，或植物仍在冷却中）会给予 `-10` 的惩罚。

## 3. 游戏前决策逻辑：卡组选择
进入关卡前，AI使用一个独立的流程来选择其植物卡组：
- **状态捕获**：`image_capturer.py` 截取游戏UI界面的屏幕截图。
- **状态分析**：`state_analyzer.py` 处理这些图像，以确定当前关卡和种子槽中可用的植物。
- **API决策请求**：`decision_client.py` 将UI状态打包为JSON格式，并向本地决策服务器发送HTTP POST请求（例如 `http://localhost:5000/decision`）。
- **执行**：服务器回复所需的策略 (`strategy`) 和具体动作 (`actions`，如选择或替换卡片)。`action_executor.py` 将这些命令转换为实际的鼠标点击来构建卡组。

## 4. 结论
AIPVZ项目展示了一种复杂的、解耦的游戏自动化方法。它使用传统的计算机视觉和基于规则的API服务器进行确定性的菜单导航（卡组选择），同时保留深度强化学习（基于CNN的DQN）来处理实时战术植物放置这种高度随机和复杂的任务。
