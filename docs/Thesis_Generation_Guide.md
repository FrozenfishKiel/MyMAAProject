## 一、 项目概述 (Project Overview)
本项目旨在解决复杂二次元塔防手游《明日方舟》的动态自动化部署问题。传统的自动化脚本（如 MAA）主要依赖固定的坐标轴流水线录制或严格的模板图像识别，缺乏应对复杂多变战局的泛化决策能力。
因此，本项目提出了一种**基于强化学习 (Reinforcement Learning, PPO 算法) 与混合机器视觉架构的智能体控制系统**。系统通过 YOLO 检测友方状态，通过 MOG2 背景建模构建“敌人动态雷达”，将游戏画面降维为 3 通道张量（灰度原图、部署网格掩膜、敌人雷达掩膜）。智能体通过马尔可夫决策过程（MDP）进行训练，能够自主决定在什么位置、以什么朝向部署干员，从而实现将卡牌“丢到敌人脸上并正对敌人”的战术动作。

## 四、 第三章 撰写指南：自动化部署系统核心架构设计

本章需要体现强大的工程落地能力和系统架构思维。

### 3.1 系统总体架构设计
描述系统的闭环运作流程：
1. **环境感知**：通过 ADB 协议获取模拟器截图。
2. **混合视觉特征提取**：利用 YOLO、MOG2 等技术提取特征。
3. **强化学习决策大脑**：PPO 神经网络根据特征输出离散动作。
4. **动作控制执行**：将动作翻译为划屏操作注入游戏。

### 3.2 混合视觉感知模块设计 (亮点)
*   **YOLO 干员状态检测**：阐述为何放弃模板匹配，转而用 YOLO 实时捕捉干员部署落地的血条中心点坐标，用于解决动态转场时的漏检问题（配合3次心跳检测机制）。
*   **MOG2 动态敌人雷达**：阐述提取背景极其复杂的游戏画面中移动敌人的方法。使用 `cv2.createBackgroundSubtractorMOG2` 提取前景，并辅以形态学滤波（开闭运算）消除特效干扰，提取敌人连通域质心。
*   **基于模板匹配的 UI 状态机导航**：简述利用 OpenCV `TM_CCOEFF_NORMED` 实现的关卡自动重启、界面跳转兜底逻辑。

### 3.3 强化学习马尔可夫决策过程（MDP）建模 (核心)
*   **状态空间 (State Space) 降维**：不使用原彩 RGB 图像，而是人工合成了高信息密度的 3 通道张量 $(C=3, H=72, W=128)$：
    *   Ch1: 游戏原画灰度图。
    *   Ch2: 提取特定 HSV 的绿色可部署区域 Mask。
    *   Ch3: 基于 MOG2 的敌人动态雷达 Mask。
*   **动作空间 (Action Space)**：定义为 MultiDiscrete 离散空间，包含 11 个维度的选卡策略（包含挂机等待）、10x5 的网格坐标选择、以及 4 个方向的朝向选择。
*   **基于空间几何的奖励函数重塑 (Reward Shaping, 重点创新)**：
    *   解释为何舍弃延迟过高、信噪比低的“游戏星级结算奖励”。
    *   阐述密集型即时奖励公式：
        1. 基础惩罚/兜底：非法区域阻断扣 0.5 分，挂机扣 0.01 分。
        2. 距离奖励：计算部署坐标与雷达探测到的敌人质心的欧氏距离，距离越近奖励越高（+2.0）。
        3. 朝向奖励：利用反正切函数 (`math.atan2`) 计算敌人相对于干员的角度，朝向一致奖励极高（+8.0），背对敌人予以惩罚（-1.0）。
